# スライドビューア（最小構成）

PDFを置くだけで、自社HPやブログにスライドとして埋め込めるビューアです。
サーバーもデータベースも使わず、GitHub Pages で無料公開できます。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `viewer.html` | PDFを1ページずつ表示するビューア。埋め込みに使うのはこのページ |
| `index.html` | 資料一覧。埋め込みコードとURLをコピーできる（社内用の管理画面） |
| `decks.json` | 資料一覧に出すPDFのリスト |
| `pdfs/` | PDFを置くフォルダ |

## 初回の公開手順（GitHub Pages）

1. GitHubで新しいリポジトリを作る（Public）
2. このフォルダの中身をすべてアップロードする
3. リポジトリの Settings → Pages を開く
4. Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存
5. 数分後、`https://<アカウント名>.github.io/<リポジトリ名>/` で一覧が開ければ完了

## 資料を追加する

1. `pdfs/` にPDFを入れる（ファイル名は半角英数字とハイフンがおすすめ）
2. `decks.json` に1件追加する

```json
{
  "title": "資料のタイトル",
  "file": "pdfs/ファイル名.pdf",
  "date": "2026-10-02"
}
```

ダウンロードボタンを消したい場合は `"download": false` を足します。
3. コミットすると、1〜2分で反映されます

## 埋め込む

一覧ページの「埋め込みコードをコピー」で、次のようなコードがコピーされます。

```html
<iframe src="https://<アカウント名>.github.io/<リポジトリ名>/viewer.html?file=pdfs/xxx.pdf&amp;title=..."
  style="width:100%;aspect-ratio:16/10;border:0;" allow="fullscreen" allowfullscreen loading="lazy"></iframe>
```

- **自社HP**：WordPress は「カスタムHTML」ブロック、STUDIO・Wix などは「埋め込み（HTML）」パーツに貼り付けます
- **note**：「URLをコピー」で取得したURLを貼ります。noteは対応サービス以外をリンクカードで表示するため、記事内でスライドはめくれず、クリックでビューアが開く形になります
- 特定のページから表示したい場合は、URLの末尾に `&page=5` を付けます

## 操作

- 次へ：右矢印キー、スペース、画面右側をクリック、左へスワイプ
- 前へ：左矢印キー、画面左側をクリック、右へスワイプ
- 全画面：Fキーまたは右下のボタン（埋め込み先で全画面が許可されていない場合は新しいタブで開きます）

## 注意点

- **公開されるのはPDFファイルそのもの**です。URLを知っていれば誰でも閲覧・保存できるので、社外秘の資料は置かないでください。`"download": false` はボタンを隠すだけで、保存を完全には防げません
- 無料プランのGitHub Pagesでは、リポジトリを Public にする必要があります（PDFもリポジトリ上で見える状態になります）
- 大きなPDFは表示が遅くなります。画像の多い資料は、PDF書き出し時に画質を下げると軽くなります
- `index.html` も公開されます。一覧を外部に見せたくない場合は削除し、URLは手元で組み立ててください（`viewer.html?file=pdfs/xxx.pdf`）
