# スライドビューア（UPWARD社 資料置き場）

Googleドライブの「HP掲載用資料」フォルダにPDFを入れるだけで、自社HPやnoteに埋め込めるスライドとして公開されます。
GitHubは表示用のページを置いているだけなので、メンバーが触る必要はありません。

## メンバー向け：資料の操作

すべてGoogleドライブの「HP掲載用資料」フォルダで行います。操作はすぐに反映されます。

| やりたいこと | 操作 |
| --- | --- |
| 追加する | フォルダにPDFをドラッグ&ドロップ |
| 更新する | 古いPDFを削除して、**同じファイル名**の新しいPDFを入れる（埋め込みはそのまま新しい内容に変わる） |
| 削除する | フォルダからPDFを削除 |
| タイトルを変える | ファイル名を変える（ファイル名がそのままタイトルになる） |

### 守ってほしいこと

- **このフォルダのPDFは誰でも閲覧・保存できます。** 社外秘の資料は入れないでください
- HPやnoteに載せた資料の**ファイル名を変える・削除すると、埋め込み先で表示されなくなります**
- PowerPoint・Googleスライド・KeynoteはPDFに書き出してから入れてください
- フォルダの中にサブフォルダを作っても、その中身は表示されません

## 埋め込む

資料一覧ページ（https://sasakis22.github.io/SlideDeck/）で操作します。

- **自社HP**：「埋め込みコードをコピー」→ HPのHTML埋め込み欄に貼る
- **note**：「URLをコピー」→ 記事に貼る（リンクカード表示になります）
- 特定のページから表示したい場合は、URLの末尾に `&page=5` を付けます
- ダウンロードボタンを消したい場合は、URLの末尾に `&download=0` を付けます

## 管理者向け

### ファイル構成

| ファイル | 役割 |
| --- | --- |
| `viewer.html` | PDFを1ページずつ表示するビューア。埋め込みに使うのはこのページ |
| `index.html` | 資料一覧。埋め込みコードとURLをコピーできる |
| `config.js` | Google Drive APIのキーと、フォルダIDの設定 |

### 仕組み

ページを開くたびに、Google Drive API で指定フォルダの中身を読み込んで表示します。
フォルダを「リンクを知っている全員が閲覧可」にしているので、ログインなしで読み込めます。
APIキーはページから見えますが、GitHub Pagesのドメインと Google Drive API に限定しているため、他のサイトでは使えません。

### 初期設定

1. Googleドライブにフォルダを作り、共有設定を「リンクを知っている全員：閲覧者」にする。メンバーは「編集者」として追加する（共有ドライブに作ると、作成者が退職してもフォルダが残るので安心）
2. Google Cloud コンソールでプロジェクトを作り、「Google Drive API」を有効にする
3. 「認証情報」で APIキーを作り、次の2つの制限をかける
   - アプリケーションの制限：ウェブサイト → `https://sasakis22.github.io/*`
   - APIの制限：Google Drive API のみ
4. `config.js` に APIキーとフォルダIDを書いて、GitHubにアップロードする
